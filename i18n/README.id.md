# ChillAgent (Bahasa Indonesia)

> **Mesin Anti-Slop 2.0 & Standar Senior Developer Pragmatis untuk Coding Agent AI.**
> Menggabungkan ketelitian visual bebas-slop dari [anti-slop](https://github.com/miqdadbadjuber/anti-slop) dengan prinsip minimalis YAGNI tanpa kompromi dari [ponytail](https://github.com/dietrichgebert/ponytail).

## Perintah Cepat

```bash
# Jalankan wizard interaktif langsung
npx chill-agent@latest

# Audit file dari gradien ungu, card mengambang & copy klise
npx chill-agent@latest audit

# Otomatis bersihkan kode dari AI slop
npx chill-agent@latest audit --fix

# Buat panduan desain kelas Linear
npx chill-agent@latest init-design
```

## Prinsip Inti
1. **The Smallest Complete Change:** Gunakan native platform dan standard library sebelum menambah dependensi eksternal.
2. **The Purpose Test:** Setiap gradien, warna, atau layout harus memiliki fungsi domain yang jelas. AI defaults (gradien ungu, rounded-3xl) dilarang.
3. **Delivery Disclosure:** Di akhir setiap jawaban teknis, sebutkan apa yang sengaja di-skip dan batas trade-off kode.
