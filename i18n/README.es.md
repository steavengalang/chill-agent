# ChillAgent (Español)

> **Motor Anti-Slop 2.0 y Estándar de Desarrollador Senior Pragmático para Agentes de IA.**
> Combina la artesanía visual de [anti-slop](https://github.com/miqdadbadjuber/anti-slop) con el minimalismo YAGNI de [ponytail](https://github.com/dietrichgebert/ponytail).

## Inicio Rápido

```bash
# Asistente interactivo
npx chill-agent@latest

# Auditoría de código
npx chill-agent@latest audit

# Reparación automática
npx chill-agent@latest audit --fix
```
