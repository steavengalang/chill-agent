# ChillAgent (简体中文)

> **面向 AI 编程助手的 Anti-Slop 2.0 引擎与极简实用高级开发者标准**
> 融合 [anti-slop](https://github.com/miqdadbadjuber/anti-slop) 的视觉精益标准与 [ponytail](https://github.com/dietrichgebert/ponytail) 的无废话极简主义 (YAGNI)。

## 快速使用

```bash
# 启动交互式配置向导
npx chill-agent@latest

# 扫描项目中的 AI 泛滥特征
npx chill-agent@latest audit

# 自动修复
npx chill-agent@latest audit --fix
```
