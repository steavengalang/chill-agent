# ChillAgent (日本語)

> **AIコーディングエージェントのためのAnti-Slop 2.0エンジン ＆ プラグマティックシニア開発者標準**
> [anti-slop](https://github.com/miqdadbadjuber/anti-slop) の視覚的クラフトマンシップと [ponytail](https://github.com/dietrichgebert/ponytail) のミニマリズム（YAGNI）を統合。

## コマンド

```bash
# 対話型ウィザード
npx chill-agent@latest

# スロップの監査
npx chill-agent@latest audit

# 自動修復
npx chill-agent@latest audit --fix
```
